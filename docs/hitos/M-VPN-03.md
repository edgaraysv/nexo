- Se intentó primero `Stop-Service -Name "NexoEndpoint" -ErrorAction Stop` desde la sesión no elevada; falló con `Cannot open NexoEndpoint service on computer '.'` (`CouldNotStopService`), sin cambiar el estado. Tras autorización explícita para elevar, un primer wrapper PowerShell mal formado falló antes de lanzar el comando de servicio (`$body` quedó vacío); no hubo mutación. El intento elevado corregido terminó con exit 0. Verificación posterior: `NexoEndpoint` `Stopped`, `ProcessId=0`, inicio `Auto`, pipe `nexo-endpoint-v1` ausente. No se desinstaló ni modificó el directorio persistente/identidad.
- Del `state.json` se extrajeron únicamente metadatos: device ID `dcb009da-b170-4fdf-93fc-6a73b3006533`, audience `endpoint`, serial `72144b12586883c740a6710e13174f4b`, certificado presente, claim token ausente y archivo de clave presente. La fecha `NotAfter` leída del certificado local es `2026-10-29T12:50:13Z`, anterior a la fecha actual de esta inspección (2026-11-07).
